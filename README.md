# ColorProbe

Пипетка для macOS в строке меню. Делает снимок экрана, на нём можно отметить любое количество точек. Для каждой точки показывается цвет в HEX, RGB, HSL, HSB и CMYK. Готовый снимок с отметками сохраняется в PNG.

Требуется macOS 14 или новее.

## Сборка

```sh
./build.sh
open build/ColorProbe.app
```

При первом снимке macOS запросит разрешение «Запись экрана».

## Использование

- ⌃⇧C или пункт в меню: снимок экрана, на котором находится курсор
- клик: новая точка; точки и таблички можно перетаскивать
- клик по строке таблички: скопировать значение
- правый клик: удалить точку, ⌘Z: отменить
- ↩: сохранить, Esc: выйти без сохранения

Папка для сохранения и язык интерфейса выбираются в меню.
